# 候选内容的依据审查

适用范围：M2-01的来源质量；不表示M2、模型行为或长期个体愿景已完成。契约见[CONTRACTS](CONTRACTS.md)，前因与检索证据见[MEMORY_RETRIEVAL](MEMORY_RETRIEVAL.md)。

## 为什么增加这条路径

此前真实人物读取实验虽能检索并定向调用工具，最终回答仍添加未给定的性别或缺少相应引用的事实。存在来源ID只能证明对象存在，不能证明它支持具体语句。新路径在实际写入之前审查候选，不依赖人格提示词中的“诚实”来代替执行约束。

## 当前机制与边界

- 非空回复、每条新记忆、每项人物关联各有一个审查目标，全部覆盖且supported才允许提交。任一目标被拒，整个候选不提交。
- 纯工具或目标变更没有这些内容时，不额外调用内容审查；原工具执行和目标成果审查继续生效。笔记是生成产物，不因此自动变成已核实知识。
- 作者和审查使用独立请求/角色/会话标识；所有调用、失败与重试共用三次上限、实际预算、时限及租约。不通过增加隐藏调用来获得“审查通过”。
- 审查请求按目标组织其声明的事件或记忆，省略作者的其余检索池。请求语境、人格、人物引用和能力状态分别标识，不自动成为事实证据。
- 当前证据包为`target-citations/3`：每项目标的可引用ID明列；实际目标状态与外界事实分开。程序生成的原子提交约束只覆盖本候选实际新记忆和新建目标；“记住/保留”的内容仍检查来源，工具成功、成果完成和外部消息仍要求真实回执。
- 当前依据足够的自然表达、推理、观点和明确假设仍可存在；不要求每句话成为逐字摘录，不把人格冻结成资料复读器。
- 审查意见可错，尤其同一模型可能重复作者的遗漏。程序验证的是覆盖、引用、版本、权限和用量，不能验证所有语义。

`decision_reviews`与`decision.reviewed`保存结构化诊断，绑定候选、作者上下文、审查上下文、已结算调用、租约与状态/隐私/配置版本，以及规则/schema/证据包版本的指纹。审查本身不提升个体状态版本；提交时再次核验。来源撤销阻断派生结果和缓存重放。

未通过则记录`decision_grounding_failed`，不发布候选、不保存候选记忆，也不无限重写。被拒草稿标记为生成内容，只在当前运行作为反馈，不能成为事实引用或记忆来源，后续运行不读取它来充当经历。完整物理删除仍须覆盖审查表和事件载荷，尚待M2-03/M5；不能将递归读取阻断称为完整删除。

普通FixtureProvider明确标记fixture_unchecked；显式审查夹具只证明执行路径，不能证明语义质量。部署环境不能选择夹具。Live缺少审查能力或调用额度时不能走夹具路径提交。

工程用例覆盖：缺失审查、被拒草稿传播、完整覆盖、未知/跨目标引用、实际用量、并发新输入、三次调用上限、证据撤销、重复提交及账本篡改。0020引入审查记录，0021扩展目标来源类型后诊断schema版本为21。新增路径没有改变冻结100题、向量排名或其93次原始禁止命中的既有结果。

内容审查与开放目标成果审查可能同时消耗额度；真实自主生命周期须另做联合回归。小规模正反例成功也不等于180次行为门槛、认知纠错、人格发展、成长对照或十四天观察完成。

v3暴露了有界循环的可用性问题，但旧报告未收集该运行的修复/工具诊断，不能断言具体是哪一步消耗了额度。新实验加入这些诊断；正常模型上下文增加运行时调用余额快照。余额在本次作者调用预留前读取，remaining包含本次调用和后续审查；它仅辅助规划，实际限制仍由账本强制执行，不改变三次上限。

联合回归继续检查真实首次阅读、跨进程恢复、局部偏好例外、自主目标与未知经历。新规划指导将工具轮中的待整理记忆集中到读取后的最终提案；原事件已保存，未假装丢失经历或预先完成行动。goal_origin_catalog由实际可见事件/兴趣生成，最多32项，has_more标识省略；当前触发事件优先，内部goal/decision/run通知不列入。目录只帮助复制正确类型和ID，不创建目标，不代替现有来源与状态校验。

作者请求中的Schema进一步按目录约束各类origin_ids，且只列入当前可见的既有目标ID；无既有目标时不展示转换分支。此为生成辅助，供应商的json_object输出不保证遵守Schema，领域校验仍是执行边界。新单元测试重放混合来源和未分配目标ID反例。v5证明仅收窄指令仍不足；下一步应完善逐条类型化的多来源表达与精确反馈，保持来源验证、原研究完成条件及调用上限，不能静默丢弃目标或把研究改成摘录来通过。

隔离验收的ObservedProvider仅记录已解析的合成作者提案、实际预算与来源目录，用于定位错误；不记录供应商原始响应、凭据或隐藏推理，也不接入生产服务或部署开关。候选状态与实际提交结果分别检查，实际结果以持久事件为准。

### 先前类型化来源切片的机制说明

已将新目标规范改为逐项`origins`引用；事件与兴趣可共同构成动机。原来的单类格式继续严格验证后显式转换，错标拒绝。持久投影增加mixed且可往返；恢复补回离开最近窗口的事件来源，无进展拦截比较类型化身份。没有缩减原研究条件；验收另明确拒绝把研究改为摘录条件来过关。

有效的unsupported/uncertain仍终止。无效审查协议可在剩余额度内重试同一候选，保留一个作者调用；重试计入同一修复次数、预算、租约和时限。固定诊断区分schema/context/targets/evidence/citations/limits，隔离实验只新增结构化审查意见或固定错误码与用量，无原始响应日志。

`target-citations/3`补充的事务约束来自现有`commit_decision`真实行为：审查和其余验证通过后，回复、新记忆、目标、关系更新及outbox在同一事务中提交；任何晚期错误都不能让声称已记录的回复单独可见。这个约束只让审查器理解何时发布，并不预先证明写入成功。新故障测试在message.created通知处强制失败，检查所有写入一起回滚，删除故障后同候选可原子提交与幂等重放。合成审查通过只验证这项事务性质，语义与真实生命周期仍分别验证。
