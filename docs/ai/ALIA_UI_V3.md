# ALIA / 彼我 WebUI v3.0 实施与验收

以用户最新17页规格为权威，替代v2十页信息架构；原始设计包保留未改。WebUI在原React/TypeScript/Vite中实施，后端沿用Rust/Axum/SQLx与原有Bearer、幂等、版本、SSE；没有第二套后台或静默Mock回退。

## 设计系统与交互

使用指定紫白色值、18px卡片、256/76px桌面侧栏和72px顶栏；深色主题与移动抽屉共用同一组件。四组菜单单独滚动，品牌与个体标记保持可见；无角色立绘、头像或背景吉祥物。功能SVG图标与字母标记不代表人物形象。字体使用Inter/Noto Sans SC/系统回退，不依赖远程字体或CDN。

保留原失败确认框不关闭、409草稿保留、SSE游标恢复、断线同步时间与页面内存鉴权。新增页面通过Repository和useResource加载，分别显示loading/error/empty并允许重试；切换页和会话后丢弃迟到结果。工作台是纯校验，不改状态、不发送模型或工具请求，提案结构通过不能替代证据/权限/版本校验。

## 新增服务契约

- `GET /runs?status=&cursor=&limit=`：按创建时间倒序的稳定分页与状态过滤；不返回输入manifest或原始错误正文。
- `GET /runs/{id}`：同一隐私快照下的本地Trace/Span元数据，最多50项；模型计费与未知用量、工具版本/实际开始结束时间和结果事件ID。步骤按真实观测时间交错排列。历史时间缺失保持null。
- `GET /audit?cursor=&limit=`：系统事件ID、序号、类型、actor、来源类型、时间、可见关联ID；不返回payload。
- `GET /diagnostics`：数据库可达、服务版本/启动、迁移、可见运行/索引统计；数据库可达不代表模型成功。
- `GET /management`：白名单提供商与审查模型名、凭证存在布尔值、计数方式、真实注册能力、Web渠道及未实现能力标志。不返回密钥、端点、任意自定义模型字符串。
- `GET /persona`：实际出生种子与当前人格，注明尚无中间修订历史/回滚。
- `POST /sandbox/validate`：kind和document_text，64KiB内严格原文校验，返回检查范围、valid和not_executed；不回显输入，不写个体数据。

均沿用原认证、同源、no-store和固定错误响应；所有来源读取继续使用递归隐私屏障。新增0019只记录未来工具的真实时间，不回填虚构历史，不改变原有请求数据模型。
