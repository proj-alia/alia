## 设计与实现

- 230px 浅色侧栏，64px 可收起模式；62px 桌面顶栏与26px状态栏；9px面板和6px控件圆角。移动端抽屉，资源选择器局部横向滚动，详情单列。
- 保留深色主题；辅助文字/语义文字采用可读性调整色，详见[决策记录](ALIA_CONSOLE_DECISIONS.md)。无角色、插画、装饰背景或渐变 Hero。
- 认知、关系、媒介、旧追踪与事件书签继续映射同一内容。原有 REST/SSE、令牌内存、版本和幂等约束保持。
- 模型/渠道/扩展采用真实资源目录。未接入能力明确标记，只读和不可用状态不会生成成功回执。
- 配置分区修改以完整文档为基础；原文 JSON 切回结构化视图前先通过服务端验证。空草稿同样属于未保存变更。
- 菜单、子页、浏览器前进后退与直接 hash 跳转受未保存保护；刷新/关闭使用浏览器原生离开提示。保存后离开依赖真实服务端写入成功，失败保留输入。

本机服务已更新到 v4 框架；只读检查确认数据库健康200、未授权401、已授权409/not_initialized及静态文件匹配。未创建生产个体。生产发布与最后一次测试状态以测试报告记录为准。旧 v3 报告保留为历史材料，不用于宣称 v4 完整验收。
