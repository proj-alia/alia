# UI 集成差异与后续依赖

- 设计包 API 是建议。实际后端采用一个个体 `/api/v1/state`，不引入多实体服务或平行身份系统；绑定主键始终为服务端 individual_id。
- 当前授权由完整 runtime 配置定义，未实现逐能力 `auto/approve/deny` 策略和外部审批状态机。UI 不创建前端审批记录；修改规则需明确确认并经既有版本校验。
- 人格展示的是当前持久配置。profile_version 为种子档案版本，state.version 为状态版本，不能冒充人格修订历史。真实发展提案与撤回在 M3。
- 记忆搜索目前只过滤已加载文本；向量检索、修订和完整删除待 M2。删除前已有浏览器展示内容无法追溯撤回；后续隐私事件必须触发重新读取并清除缓存。
- 关系页无独立对象列表；认知页无持久信念 API；事件页只有真实交流事件。不要把当前消息视图标为完整不可变审计。完整关系/信念/审计 API 接通后再增加相应操作。
- 后端已完成七天 outbox 通知续接，但并非消息正文归档。过期返回410，页面重新获取快照。每实例最多16个流，缓冲最多100条元数据；无令牌 URL、持久浏览器令牌或未验证模型 token 流。
- 历史元数据可能已经送入网络缓冲，不能保证撤回。再次获取资源始终重新检查来源阻断。以后实现隐私清理时，privacy.changed 应引用有效的个体级标识，以便所有视图刷新。
- 原型配色保持；功能链接和小字用 accentStrong/secondary，未宣称完成所有 WCAG 自动化审计。移动抽屉和确认框已有实际键盘测试。
- 指定Go/GLM-5.3-Flash已开放保守预算下的真实调用，其他未验证路径仍拒绝。UI区分ready、unavailable与unverified_token_bound；ready不保证远端在线或行为全面达标。契约与真实试验见../MODEL_BUDGET.md。
- 回滚前端可替换静态构建，不得重置数据库。0010 迁移只增加通知水位表与索引，不更改人格/记忆；不通过删除数据库回退 UI。
- 本次未加入外部字体/CDN、图片生成、人物立绘、头像或插画。原型 screenshots 只作设计参考，不被生产代码引用。

- 当前视图JSON下载已实现；它只导出浏览器已获授权读取的显式投影，不是全量备份。事件文件可能含私人消息，确认框明确说明；断线时保留实际同步时间及连接状态，不宣称最新。服务端完整导出仍依赖后续里程碑。

人物引用检查边界：已能读取保存的主体/提及注记及实际来源；字面引用校验不能证明主体语义和身份真实。真实模型开发试验曾省略关联却声称完成，失败记录保留；UI只展示服务端实际注记，不以回复文字推断成功。摘要可能同时夹带多个人物事实，尚未证明检索纯净度。注记不是完整关系档案，也没有开放人物写入或身份验证功能。

## v3边界

17页已成为当前信息架构，底层业务完成度以ALIA_UI_V3表格为准。工作台当前是真实服务端隔离静态校验，不是模型或工具执行沙盒；追踪是本地运行/步骤元数据，不暴露原始payload或服务器日志。无真实数据时显示空/未知/未实现，不能把未接入审批数量当0，也不能将模型配置就绪当成连通性测试成功。没有提供浏览器密钥写入或本地存储功能。
