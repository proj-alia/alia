## 已接通

十页：个体总览、身份与人格、记忆档案、认知画像、关系脉络、意图与行动、感知与媒介、授权与治理、事件回溯、运行与设置。统一身份和规则来自 `/state`，消息/记忆/目标来自分页接口，操作状态来自 `/operations/{id}`。SSE 只通知已提交资源，由页面重新读取有效数据。无假健康分数、虚构运行时长、亲密度积分、模拟审批或隐藏 Mock。

记忆检查支持当前加载页的文本和类别筛选、来源 ID、适用范围、有效状态和分页。关系页展示真实交流和当前初始关系规则，认知页展示当前人格中的认知偏好及目标，均不冒充尚未实现的独立领域投影。事件页明确只含交流事件。

结构：`web/src/app/App.tsx`、`design-system`、`shared/repository.ts`、`shared/useIndividual.ts`、`features/*.tsx`。没有图片/角色渲染依赖；仅字母 A、几何标记和设计包中的静态 SVG 功能图标。哈希路由避免新增框架并支持刷新/历史导航。主题属于内存显示状态，令牌不进入 URL/浏览器持久存储。

目标管理已接通持久创建、等待、激活和放弃；确认框保留打开时的目标版本和变更理由。来源事件、无进展轮次及真实变更回执可检查；终态目标无重开或手工完成入口。
